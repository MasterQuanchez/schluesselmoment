## How to use this file

- When writing documentation, meeting summaries, or code comments in tracked files,
  use the abbreviation column instead of the full name
- If a new entity needs an abbreviation, add it here before using it in tracked files
- Vendor names used in daily work (SAP, Azure, Zebra, etc.) are acceptable as-is — they
  don't need abbreviation entries unless there's a confidentiality concern
