# Sourcing

Staging area for raw inputs, scratch extraction output, and drafts in flight. Promote durable knowledge into `knowledge/`, `memory/`, or `data-products/` before citing it as ground truth.

- `raw/` - raw source material; keep sensitive material out of git.
- `scratch/` - generated extraction output and temporary analysis.
- `drafts/` - tracked drafts that are not yet promoted.
